ICT251 Activity 3 Web Development Project

This website project was created for ICT251 Activity 3 at Mulungushi University by Thresa Mulenga. The project demonstrates fundamental web development techniques by combining structured HTML5 elements, custom CSS styling, dynamic JavaScript interactivity, and embedded multimedia assets. The core structure is organized in a clear, standardized architecture: index.html serves as the primary landing page, the css/ directory contains styles.css for layout and visual styling, the js/ directory holds script.js for client-side interactivity, and dedicated images/ and videos/ folders store all visual and audio media. The entire repository is managed using Git version control and hosted on GitHub to support seamless deployment as a static site on Render.
